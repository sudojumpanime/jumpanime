## Features

- **AniList sign-in.** Your lists, scores and progress sync with your AniList account.
- **Discover.** Search by name, or mix several genres and filters at once. Tap a genre on any anime page to jump straight into it.
- **A proper player.** Gestures, double-tap to seek, hold for fast-forward, skip intro and outro, picture-in-picture and Chromecast.
- **Several sources with automatic fallback.** If one source fails, JumpAnime tries the next one for you. You can also pick a source yourself in Settings.
- **Sub and dub.** Choose the audio you want per episode.
- **Downloads.** Save episodes to watch offline, in the quality you pick. There is an optional *Fast downloads* mode and a Wi-Fi-only switch.
- **Comments.** Talk about each anime with other viewers.
- **Your choice on adult titles.** They are shown by default, and one switch in Settings hides them.
- **Updates inside the app.** JumpAnime tells you when a new version is out.

## Install

1. Open the [latest release](https://github.com/sudojumpanime/jumpanime/releases/latest) on your phone.
2. Download the `.apk` file under **Assets**.
3. Open it and allow *Install from this source* if Android asks.

Needs Android 8.0 or newer.

## Questions

**Is it free?** Yes, and it has no ads.

**Does JumpAnime host any videos?** No. It doesn't store or host any video. Episodes come from third-party public sources, and availability depends on them.

**Why did a video stop working?** Sources change from time to time. Try another source in *Settings → Playback → Stream source*, then let me know in [Issues](https://github.com/sudojumpanime/jumpanime/issues).

**Is the source code available?** Not at the moment. This repository only contains the releases.

**Found a bug or have an idea?** Open an [issue](https://github.com/sudojumpanime/jumpanime/issues).
